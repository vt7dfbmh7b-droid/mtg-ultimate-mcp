# V0.13 — NZD-First Pricing

V0.13 makes **New Zealand dollars (NZD)** the primary user-facing currency in MTG Ultimate.

The rule is simple:

> **Show and accept budgets in NZD first. Keep USD only as a clearly labelled source/reference value when the upstream market data is USD.**

## Pricing priority

1. A directly checked New Zealand listing for the **exact physical printing** is preferred when available.
2. TCGfind NZ and New Zealand retailers are the preferred local shopping/reference lane.
3. When no structured NZ-local price is available, MTG Ultimate converts the exact Scryfall USD printing reference into NZD.
4. The original USD reference remains attached for traceability, but it is not the primary displayed price.
5. Converted prices are estimates and are not presented as guaranteed New Zealand checkout or landed costs.

Printing restrictions still come first. A cheaper unrelated printing cannot replace a required Final Fantasy, Marvel, Secret Lair, promo, foil or other requested physical version.

## Exchange rate

V0.13 uses the Frankfurter v2 USD/NZD rate endpoint by default and caches the rate for six hours.

Configuration:

```text
FX_API_BASE=https://api.frankfurter.dev
FX_CACHE_MS=21600000
USD_TO_NZD_FALLBACK=
```

`USD_TO_NZD_FALLBACK` is intentionally blank by default. If live FX is unavailable and there is no cached rate, MTG Ultimate fails clearly rather than silently inventing an exchange rate. A manually configured fallback can be used when desired and is labelled stale/fallback in output.

## New tools

### `pricing_policy_v13`
Shows the current USD→NZD rate and the pricing priority rules.

### `price_card_nzd_v13`
Prices a named card or exact set/collector-number printing. Output uses `priceNzd` first and retains `priceUsdReference` only for traceability.

### `refine_commander_deck_v13`
Uses:

- `maxNzdPerCard`
- `maxTotalNzd`

The workflow converts those limits internally only where an upstream USD reference is required, then converts all monetary output back to NZD-first fields.

### `refine_precon_v13`
Same NZD-first behavior for stock Commander precons.

Default V0.13 profiles are expressed directly in NZD:

- light: NZ$10/card
- balanced: NZ$20/card
- strong: NZ$35/card
- optimized: no default per-card cap

The caller can override these values.

### `build_and_refine_commander_deck_v13`
Uses:

- `maxNzdPerCard`
- `maxPostDraftUpgradeNzd`

for from-scratch construction plus refinement.

## Backward compatibility

V0.12 and earlier tools remain registered for compatibility and may still contain USD-named internal fields. Current clients should prefer the V0.13 tools for pricing, building and refinement.

The V0.13 wrapper converts legacy monetary fields such as:

```text
priceUsd                    -> priceNzd + priceUsdReference
estimatedUpgradeSpendUsd    -> estimatedUpgradeSpendNzd + estimatedUpgradeSpendUsdReference
maxTotalUsd                 -> maxTotalNzd + maxTotalUsdReference
```

This preserves auditability without making USD the normal user-facing currency.

## Testing

The live smoke suite now checks:

- the live USD→NZD FX source
- an exact Scryfall printing price converted to NZD
- that pricing output exposes `priceNzd` rather than a bare primary `priceUsd`

The full Commander E2E scenario now sends an NZ$ total budget and NZ$ per-card budget, then verifies the final precon upgrade package remains within those NZD limits while preserving exact printing identity and Commander legality.
